# Project skills

Vendored from [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) (MIT, commit `ce26fc2`).

- `design-taste-frontend`: anti-slop frontend design rules for landing pages and portfolios.
- `redesign-existing-projects`: audit-first upgrade checklist for an existing site (fits this repo's `index.html` + `styles.css`).

Claude Code loads these automatically from `.claude/skills/`. Invoke with `/design-taste-frontend` or `/redesign-existing-projects`.

Vendored from [JuliusBrussee/caveman](https://github.com/JuliusBrussee/caveman) (MIT, commit `aeb45e2`).

- `caveman`: terse reply style that cuts filler but keeps every technical fact. On until "stop caveman" or "normal mode".
- `ultracave`: maximum compression variant (`/ultracave` or `/caveman ultra`).
- `megacave`: Classical Chinese variant (`/megacave` or `/caveman wenyan`).

Vendored from [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) (MIT, commit `c982cd4`).

- `ponytail`: simplest-solution coding mode (reuse, stdlib, native before new code). Levels: `/ponytail lite|full|ultra`. Off with "stop ponytail".
- `ponytail-review`: over-engineering review of a diff, lists what to cut.
- `ponytail-audit`: same, across the whole repo.
- `ponytail-debt`: collects `ponytail:` shortcut comments into a ledger.
- `ponytail-gain`: shows the upstream benchmark scoreboard.
- `ponytail-help`: quick-reference card. Its auto-start and config notes apply to the plugin install, not this vendored copy.
